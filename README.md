# Data Warehousing and Data Mining (21CSE321T)

This repository contains Python-based implementations of the nine assignment topics from the assignment sheet. These versions use Python instead of Orange Data Mining.

## Requirements
- Python 3.9+
- pandas
- numpy
- scikit-learn
- matplotlib

Install dependencies:
```bash
pip install -r requirements.txt
```

## Assignments
1. Data Cleaning — `01_data_cleaning.py`
2. Data Reduction — `02_data_reduction.py`
3. Data Transformation — `03_data_transformation.py`
4. Association Rules using Apriori — `04_apriori_association_rules.py`
5. Statistical Analysis — `05_statistical_analysis.py`
6. Regression — `06_regression.py`
7. Outlier Analysis — `07_outlier_analysis.py`
8. K-means on Iris — `08_kmeans_iris.py`
9. Simple K-means clustering on Iris — `09_iris_clustering.py`

## Run
From this folder, run an assignment with:
```bash
python 01_data_cleaning.py
```
Change the filename to run another assignment.

**Academic note:** The original assignment sheet specifies Orange for several tasks. Confirm with your lecturer that Python implementations are accepted as an alternative before submission.
